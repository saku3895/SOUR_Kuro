関節角度計算の修正点
====================

対象:
src/pose_estimation/calculate_joint_angles.py

この文書は、関節角度計算について修正前と修正後で変更された部分だけをまとめたものです。

1. 骨の基準軸をX軸からY軸へ変更
--------------------------------

修正前:
    関節から子関節へ向かう骨の方向をローカルX軸としていた。

修正後:
    関節から子関節へ向かう骨の方向をローカルY軸とした。

    Y軸 = 骨の方向
    Z軸 = 基準ベクトルとY軸の外積
    X軸 = Y軸とZ軸の外積

これにより、X軸回転を人体の屈曲方向として扱い、オイラー角
[Z, X, Y] のX成分をPitchとして利用できるようにした。

2. 全身共通のフレーム計算を部位別の計算へ変更
------------------------------------------------

修正前:
    肩・肘・脚など、すべての関節を同じ
    _frame_from_direction() の計算方法で処理していた。

修正後:
    肩と腕は腕専用の計算へ分岐し、それ以外の関節は
    _build_frame() で処理するようにした。

    一般の関節:
        body_lateral = 左股関節から右股関節への方向
        を基準ベクトルとして使用する。

3. 肩関節のローカル座標系を変更
--------------------------------

修正前:
    肩も骨方向だけから一般的なローカルフレームを作っていた。

修正後:
    上腕と前腕の両方を使って肩フレームを構築する。

    upper_arm = 肩から肘へのベクトル
    forearm   = 肘から手首へのベクトル
    肩のローカルY軸 = normalize(upper_arm)

肩のX軸の基準は、身体の上方向を上腕に直交投影して作る。

    reference_x =
        body_up - dot(body_up, y_axis) * y_axis

この基準X軸は、肘のヒンジ軸が不安定な場合のフォールバックにも使う。

4. 肘の屈曲軸を明示的に計算
----------------------------

修正前:
    肘を一般の関節と同じ方法で処理していたため、
    実際の肘の屈曲がローカルZ軸などの回転として
    分解される場合があった。

修正後:
    上腕と前腕の外積から肘のヒンジ軸を求める。

    hinge_x = cross(upper_arm, forearm)

この軸を肩と肘のローカルX軸として採用する。

    肘のヒンジ軸 = 上腕 × 前腕

上腕と前腕が一直線の場合は外積がほぼゼロになるため、
身体の上方向から作ったreference_xを使用する。

また、姿勢によってX軸の正負が反転しないように、
reference_xとの内積が負の場合はX軸を反転する。

5. 肘の屈曲をX軸回転として計算
--------------------------------

修正前:
    肘フレームを座標から一般的に構築していた。

修正後:
    肩フレームを基準にして、前腕の方向をX軸回転として計算する。

    forearm_axis = normalize(forearm)
    angle = atan2(
        dot(forearm_axis, shoulder_z_axis),
        dot(forearm_axis, shoulder_y_axis)
    )

    elbow_rotation = Rotation.from_euler("x", angle)
    elbow_frame = shoulder_frame @ elbow_rotation

つまり、肘の屈曲は明示的にローカルX軸回転として扱う。
オイラー角の並びが[Z, X, Y]であるため、
このX軸回転はPitchとして出力される。

6. 肘・手首のフレームの扱いを変更
----------------------------------

修正前:
    肘と手首をそれぞれ独立した一般フレームとして計算していた。

修正後:
    肩から計算した肘フレームを使用する。

    frames[肩]  = shoulder_frame
    frames[肘]  = elbow_frame
    frames[手首] = elbow_frame

現在の15関節モデルでは、手首の独立した回転は座標から求めず、
肘フレームを引き継ぐ。

7. 頭部の骨方向を変更
----------------------

修正前:
    headからnoseへの方向を頭部の基準方向としていた。

修正後:
    neckからheadへの方向を頭部のローカルY軸とする。

    y_vec = head - neck

このベクトルがゼロに近い場合だけ、headからnoseへの方向を
代替として使用する。

8. ルート関節のカメラ座標補正を追加
------------------------------------

修正前:
    親を持たないhipsのフレームをそのまま角度へ変換していた。

修正後:
    カメラ座標系と人体のニュートラル座標系を合わせるため、
    ルート専用の補正行列を追加した。

    _CAMERA_NEUTRAL_ROTATION = diag(1, -1, -1)

hips:
    relative = _CAMERA_NEUTRAL_ROTATION.T @ frames["hips"]

親を持つ関節:
    relative = frames[parent].T @ frames[joint]

最後に、相対回転行列をSciPyのzxy順オイラー角へ変換する。

    Rotation.from_matrix(relative).as_euler("zxy", degrees=True)

まとめ
------

修正前:
    全関節をほぼ同じ方法で計算し、骨方向をX軸としていた。
    肘の屈曲軸は明示的に定義されていなかった。

修正後:
    骨方向をY軸へ変更した。
    肩・肘には専用の座標系を導入した。
    上腕と前腕の外積から肘のヒンジ軸を計算した。
    肘の屈曲をローカルX軸回転として計算した。
    その結果、肘の屈曲がPitchとして出力されるようになった。
