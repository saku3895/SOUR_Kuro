## 🎮 LobotServoController

### 概要

Hiwonder製サーボモーターコントローラと通信するクラスです。シリアル通信で独自プロトコルを使用します。

### 動作確認済み
- Hiwonder Serial Bus Servo Controller
- Hiwonder 16 Channel Servo Controller LSC-16

### クラス構造

```python
class LobotServoController:
    # フレームヘッダーと命令コード
    FRAME_HEADER = 0x55
    CMD_SERVO_MOVE = 0x03
    CMD_ACTION_GROUP_RUN = 0x06
    CMD_ACTION_GROUP_STOP = 0x07
    CMD_ACTION_GROUP_SPEED = 0x0B
    CMD_GET_BATTERY_VOLTAGE = 0x0F
    
    def __init__(self, port='/dev/ttyAMA0', baudrate=9600, timeout=0.1):
        """
        Parameters
        ----------
        port : str
            シリアルポート名 (例: '/dev/ttyAMA2')
        baudrate : int
            ボーレート (デフォルト: 9600)
        timeout : float
            タイムアウト (秒)
        """
```

参照: [../src/communication/lobot_serial_communication.py](../src/communication/lobot_serial_communication.py:4-30)

### 主要メソッド

#### `connect()`

シリアルポートに接続します。

```python
def connect(self):
    """
    シリアルポートに接続
    
    Returns
    -------
    bool
        接続成功時はTrue、失敗時はFalse
    """
    try:
        self.ser = serial.Serial(
            self.port,
            self.baudrate,
            timeout=self.timeout
        )
        self.is_connected = True
        print(f"Connected to {self.port} at {self.baudrate} baud")
        return True
    except Exception as e:
        print(f"Failed to connect: {e}")
        self.is_connected = False
        return False
```

```python
def disconnect(self):
    """シリアルポートとの接続を閉じる"""
    if self.ser and self.ser.is_open:
        self.ser.close()
        self.is_connected = False
        print("Disconnected")
```

#### `moveServo(servo_id, position, move_time)`

単一のサーボモータを制御します。

```python
def moveServo(self, servo_id, position, move_time):
    """
    単一のサーボモータを制御
    
    Parameters
    ----------
    servo_id : int
        サーボID (0-31)
    position : int
        目標位置 (0-1000)
    move_time : int
        移動時間 (ミリ秒)
    """
    self._check_connection()
    
    if servo_id > 31 or move_time <= 0:
        print("Invalid servo ID or move time")
        return
    
    # プロトコルに従ってデータを構築
    tx_buf = bytearray([
        self.FRAME_HEADER,           # 0x55
        self.FRAME_HEADER,           # 0x55
        8,                           # データ長
        self.CMD_SERVO_MOVE,         # 0x03
        1,                           # サーボ数
        self._get_low_byte(move_time),
        self._get_high_byte(move_time),
        servo_id,
        self._get_low_byte(position),
        self._get_high_byte(position)
    ])
    
    self.ser.write(tx_buf)
    print(f"Moving servo ID {servo_id} to position {position} in {move_time}ms")
```

参照: [../src/communication/lobot_serial_communication.py](../src/communication/lobot_serial_communication.py:72-100)

#### `moveServos(servo_positions, move_time)`

複数のサーボモータを同時に制御します。

```python
def moveServos(self, servo_positions, move_time):
    """
    複数のサーボモータを同時に制御
    
    Parameters
    ----------
    servo_positions : list[tuple]
        [(servo_id, position), ...] のリスト
        例: [(1, 500), (2, 750), (3, 250)]
    move_time : int
        移動時間 (ミリ秒)
    """
    self._check_connection()
    
    num_servos = len(servo_positions)
    data_length = num_servos * 3 + 5
    
    tx_buf = bytearray([
        self.FRAME_HEADER,
        self.FRAME_HEADER,
        data_length,
        self.CMD_SERVO_MOVE,
        num_servos,
        self._get_low_byte(move_time),
        self._get_high_byte(move_time)
    ])
    
    # 各サーボのIDと位置を追加
    for servo_id, position in servo_positions:
        tx_buf.append(servo_id)
        tx_buf.append(self._get_low_byte(position))
        tx_buf.append(self._get_high_byte(position))
    
    self.ser.write(tx_buf)
```

### 通信プロトコル

#### フレーム構造

```
+--------+--------+--------+-----+-----+-----+-----+-----+-----+-----+
| Header | Header | Length | CMD | Num |  Time   | ID1 |  Pos1   | ...
|  0x55  |  0x55  |        |     |     | L  | H  |     | L  | H  |
+--------+--------+--------+-----+-----+-----+-----+-----+-----+-----+
```

- **Header**: 固定値 0x55 0x55
- **Length**: データ長 = サーボ数 × 3 + 5
- **CMD**: コマンドコード (0x03 = サーボ移動)
- **Num**: 制御するサーボの数
- **Time**: 移動時間 (リトルエンディアン)
- **ID**: サーボID
- **Pos**: 目標位置 (リトルエンディアン)

### 使用例

```python
from src.communication.lobot_serial_communication import LobotServoController

# 初期化
lsc = LobotServoController(port='/dev/ttyAMA2', baudrate=9600)

# 接続
if lsc.connect():
    # 単一サーボを動かす
    lsc.moveServo(servo_id=1, position=500, move_time=1000)
    
    # 複数サーボを同時に動かす
    servo_commands = [
        (1, 500),
        (2, 750),
        (3, 250),
        (4, 600)
    ]
    lsc.moveServos(servo_commands, 1000)
    
    # 切断
    lsc.disconnect()
```

#### `receive_data()`

UnitV2からJSONデータを受信します。

```python
def receive_data(self):
    """
    シリアルからデータを受信
    
    改行文字まで読み取り、UTF-8でデコードします。
    
    Returns
    -------
    str
        受信したデータ (JSON形式の文字列)
    """
    self._check_connection()
    
    # 改行文字まで読み取り
    data = self.serial.readline().decode('utf-8')
    return data
```

参照: [../src/communication/unitv2_serial_communication.py](../src/communication/unitv2_serial_communication.py:31-36)

### データフォーマット

UnitV2から送信されるデータはJSON形式です:

```json
{
    "detected": true,
    "objects": [
        {
            "label": "person",
            "confidence": 0.95,
            "x": 120,
            "y": 80,
            "width": 100,
            "height": 150
        }
    ]
}
```

### 使用例

```python
from src.communication.unitv2_serial_communication import UnitV2SerialCommunication
import json

# 初期化
unitv2 = UnitV2SerialCommunication(port='/dev/ttyAMA4', baudrate=115200)

# 接続
if unitv2.connect():
    # データ受信
    json_str = unitv2.receive_data()
    
    # JSONパース
```

## 📏 MPU6886

### 概要

MPU6886 IMUセンサーとI2C通信で加速度・ジャイロ・温度データを取得するクラスです。

### クラス構造

```python
class MPU6886:
    def __init__(self, bus_number=1, address=0x68):
        """
        Parameters
        ----------
        bus_number : int
            I2Cバス番号 (Raspberry Piでは通常1)
        address : int
            I2Cアドレス (デフォルト: 0x68)
        """
        self.bus = SMBus(bus_number)
        self.address = address
        self.accel_scale = 0
        self.gyro_scale = 0
```

### レジスタ定数

```python
class MPU6886Constants(Enum):
    IMU_6886_ADDRESS = 0x68
    IMU_6886_WHOAMI = 0x75
    IMU_6886_ACCEL_XOUT_H = 0x3B
    IMU_6886_GYRO_XOUT_H = 0x43
    IMU_6886_TEMP_OUT_H = 0x41
    IMU_6886_PWR_MGMT_1 = 0x6B
    # ... その他のレジスタ定義
```

参照: [../src/communication/mpu6886.py](../src/communication/mpu6886.py:8-56)

### 主要メソッド

#### `initialize()`

センサーを初期化します。

```python
def initialize(self):
    """
    MPU6886を初期化
    
    パワーマネジメント、加速度計、ジャイロスコープの
    設定を行います。
    """
    # デバイスをリセット
    self._write_byte(MPU6886Constants.IMU_6886_PWR_MGMT_1.value, 0x00)
    time.sleep(0.01)
    
    # 加速度計を設定 (±8G)
    self._write_byte(MPU6886Constants.IMU_6886_ACCEL_CONFIG.value, 0x10)
    
    # ジャイロスコープを設定 (±2000dps)
    self._write_byte(MPU6886Constants.IMU_6886_GYRO_CONFIG.value, 0x18)
```

#### `get_accel_data()`

加速度データを取得します。

```python
def get_accel_data(self):
    """
    加速度データを取得
    
    Returns
    -------
    list[float, float, float]
        [ax, ay, az] - X, Y, Z軸の加速度 (G)
    """
    ax, ay, az = self.get_accel_adc()

    ax *= self.a_res
    ay *= self.a_res
    az *= self.a_res

    return [ax, ay, az]
```

#### `get_gyro_data()`

ジャイロスコープデータを取得します。

```python
def get_gyro_data(self):
    """
    ジャイロスコープデータを取得
    
    Returns
    -------
    list[float, float, float]
        [gx, gy, gz] - X, Y, Z軸の角速度 (dps)
    """
    gx, gy, gz = self.get_gyro_adc()

    gx *= self.g_res
    gy *= self.g_res
    gz *= self.g_res

    return [gx, gy, gz]
```

#### `get_temp_data()`

温度データを取得します。

```python
def get_temp_data(self):
    """
    温度データを取得
    
    Returns
    -------
    float
        温度 (℃)
    """
    temp = self.get_temp_adc()

    temp = temp/326.8 + 25.0

    return temp
```
