# 📖 1. 概要

## プロジェクト概要

**SOUR (Simple Operation for Ubiquitous Robotics)** は、セットアップ不要で軽快に使えるPython製のロボット用ミドルウェアです。

<p align="center">
    <img width="400" height="400" alt="SOUR Logo" src="https://github.com/user-attachments/assets/b431c4bf-9913-4f6d-8efd-fa7d2220e88e" />
</p>

### 🎯 目的

ロボット開発において、複数のセンサーやアクチュエータを異なる周期で制御する必要がある場面は多くあります。SOURは、このような複雑な並列処理を簡単かつ直感的に記述できるフレームワークを提供します。

---

## ✨ 主な特徴

### 1. セットアップ不要
- Pythonのみで完結
- 複雑な設定ファイル不要
- すぐに開発を始められる

### 2. Arduino風の直感的な記述
- `execute_periodic_task()` メソッドがArduinoの`loop()`に相当
- 定期実行処理を自然に記述可能
- 初心者にも理解しやすい設計

### 3. マルチプロセス並列実行
- 各モジュールが独立したプロセスとして実行
- 異なる実行周期を個別に設定可能
- ロボットのセンサー、アクチュエータ、意思決定部分を分離して管理

### 4. モジュールの再利用性
- `PeriodicModule`を継承してカスタムモジュールを作成
- 作成したモジュールは他のプロジェクトでも利用可能
- プラグイン形式で機能を追加

### 5. 共有メモリによるデータ交換
- 共有メモリ`data_dict`を通じてモジュール間でデータを共有
- 排他制御による安全なアクセス
- シンプルなAPIで複雑な並列処理を実現

---

## 🤖 設計思想

### Arduino風の使いやすさ
SOURはArduinoの`setup()`と`loop()`の概念を採用しています。これにより、組み込みシステムに慣れた開発者がスムーズに移行できます。

### モジュール性の追求
各機能を独立したモジュールとして実装することで、メンテナンス性と再利用性を高めています。

### リアルタイム性の考慮
厳密なリアルタイム保証はありませんが、実行間隔を適切に設定することで、多くのロボティクスアプリケーションで十分な性能を発揮します。

## 🚀 主な機能

### コアコンポーネント

| コンポーネント | 説明 |
|--------------|------|
| `RobotCore` | モジュール管理と実行制御 |
| `PeriodicModule` | 定期実行モジュールの基底クラス |
| `RobotProperties` | ロボット身体に関する情報を管理 |
| `AsyncModule` | 非同期実行モジュールの基底クラス（現在未使用） |

詳細は [コアコンポーネント](./05-コアコンポーネント.md) を参照してください。

### 定期実行モジュール

| モジュール | 機能 |
|----------|------|
| `PMServoControl` | サーボモータ制御のスーパークラス（デバッグ利用も可） |
| `PMServoControlHiwonderSerialBusServoController` | サーボモータドライバHiwonder Serial Bus Servo Controller利用時用サーボモータ制御 |
| `PMUnitV2` | M5Stack UnitV2 AIカメラ連携 |
| `PMMPU6886IMU` | MPU6886 IMUセンサー |

詳細は [モジュール解説](./06-モジュール解説.md) を参照してください。

## 📝 基本的な使い方

```python
from src.core.robot_core import RobotCore
from src.core.robot_properties import RobotProperties
from src.modules.pm_servo_control import PMServoControl

# 1. ロボットの身体の情報を設定
robot_properties = RobotProperties()
robot_properties.num_servos = 4
robot_properties.servo_ids = [0, 1, 2, 3]

# 2. RobotCoreインスタンスを作成
r_core = RobotCore(robot_properties)

# 3. 定期実行間隔を定めてモジュールを登録
r_core.register_module(PMServoControl(robot_properties, 50))

# 4. 実行
r_core.run()
```
