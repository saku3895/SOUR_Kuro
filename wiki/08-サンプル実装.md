#### 実行ロジック

```python
def execute_periodic_task(self, lock, data_dict):
    super().execute_periodic_task(lock, data_dict)
    
    # サーボが準備完了 かつ 新しいコマンドが未送信
    if data_dict['servo_ready'] == True and data_dict['servo_params_updated'] == False:
        
        # インターバル時間の処理
        if self.next_motion_interval > 0:
            self.next_motion_interval -= self.interval_ms
        else:
            # モーションの次のフレームを取得
            if not self.current_motion.is_motion_finished():
                position, time, interval = self.current_motion.get_next_motion()
                
                # サーボコマンドを送信
                self.write_servo_positions(lock, data_dict, position, time)
                
                self.next_motion_interval = interval
            else:
                # モーション完了時、次のモーションに遷移
                if self.current_motion == self.demo_motion1:
                    self.current_motion = self.demo_motion2
                    print("demo_motion2")
                elif self.current_motion == self.demo_motion2:
                    self.current_motion = self.demo_motion3
                    print("demo_motion3")
                elif self.current_motion == self.demo_motion3:
                    self.current_motion = self.demo_motion1
                    print("demo_motion1")
```

## 🎬 Motionクラス

### 概要

モーションデータを管理し、フレームごとの位置・時間・インターバルを提供するクラスです。

### 主要機能

1. **複数フレームの管理**: 連続したポーズを定義
2. **ループ再生**: 指定回数繰り返し
3. **ランダム変動**: 動きに自然なばらつきを追加
4. **ランダマイザー**: 特定のサーボに限定した変動

### 基本的な使い方

```python
from src.test.motion import Motion

# モーションデータの定義
positions = [
    [1500.0, 1500.0, 1500.0, 1500.0],
    [1800.0, 1200.0, 1800.0, 1200.0]
]

times = [
    [1000.0, 1000.0, 1000.0, 1000.0],
    [1000.0, 1000.0, 1000.0, 1000.0]
]

intervals = [500.0, 500.0]

# Motionオブジェクトを作成
motion = Motion(
    positions,
    times,
    intervals,
    loop_time=3,  # 3回ループ
    fluc_type=Motion.FLUCTUATION_TYPE_UNIFORM,
    fluc_amp_motion=50,
    fluc_amp_time=100,
    fluc_amp_interval=200
)

# フレームを順次取得
while not motion.is_motion_finished():
    position, time, interval = motion.get_next_motion()
    # サーボコマンドを送信
    write_servo_positions(lock, data_dict, position, time)
```

## 🎯 実装のポイント

### 1. モーション遷移のパターン

```python
# 状態機械パターン
if self.current_motion == self.motion_a:
    self.current_motion = self.motion_b
elif self.current_motion == self.motion_b:
    self.current_motion = self.motion_c
elif self.current_motion == self.motion_c:
    self.current_motion = self.motion_a
```

### 2. インターバルの処理

```python
if self.next_motion_interval > 0:
    self.next_motion_interval -= self.interval_ms  # 待機時間を減らす
else:
    # 次のフレームを実行
    position, time, interval = self.current_motion.get_next_motion()
    self.write_servo_positions(lock, data_dict, position, time)
    self.next_motion_interval = interval
```

### 3. サーボ準備完了の確認

```python
# サーボが準備OK かつ 新しいコマンドが未送信の状態を確認
if data_dict['servo_ready'] == True and data_dict['servo_params_updated'] == False:
    # 次のモーション実行
```
